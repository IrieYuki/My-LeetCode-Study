# 复杂度分析：时间复杂度 & 空间复杂度

> 来源：LeetCode 238（除自身以外数组的乘积）

## 一、一句话本质

- **时间复杂度**：当输入规模 `n` 变大时，你的**运算量**增长得有多快。
- **空间复杂度**：当输入规模 `n` 变大时，你**额外占用的内存**增长得有多快。

它们描述的是「**增长趋势的形状**」，不是「具体跑了几秒 / 占了几 MB」。

---

## 二、时间复杂度

### 1. 类比理解
- 分披萨：人数翻倍，要切的刀数也翻倍 → **线性增长 O(n)**。
- 握手：n 个人两两握一次手，人数翻倍，握手次数变成 4 倍 → **平方增长 O(n²)**。

### 2. Big O 化简规则
只保留**增长最快的一项**，扔掉常数和低阶项：
- `O(2n)` → `O(n)`
- `O(100n²)` → `O(n²)`
- `O(n² + 3n + 100)` → `O(n²)`（n 很大时 n² 碾压其余所有项）

### 3. 常见复杂度等级（从快到慢）

| 符号 | 名字 | 常见场景 |
|---|---|---|
| O(1) | 常数 | 取 `nums[0]`、哈希表查一次 |
| O(log n) | 对数 | 二分查找（每次砍一半）|
| O(n) | 线性 | 遍历一遍数组 |
| O(n log n) | 线性对数 | 快速排序、归并排序 |
| O(n²) | 平方 | 两层嵌套循环 |
| O(2ⁿ) | 指数 | 暴力枚举所有子集 |

### 4. 直观差距（n = 10⁵ = 十万）
- O(n) ≈ 10⁵ 次
- O(n²) ≈ 10¹⁰ 次（100 亿）
- 计算机 1 秒约跑 10⁸ ~ 10⁹ 次简单运算 → **n = 10⁵ 时 O(n²) 必然超时**

### 5. 如何数复杂度（循环规则）
- 一层循环、每轮 O(1) → **O(n)**
- 两层**嵌套**循环、每层 n 次 → **O(n²)**
- ⚠️ 「两层循环」**不等于** O(n²)：关键看**内层跑几次**。内层若只跑固定 3 次 → 仍 O(n)。

## 三、空间复杂度

### 1. 约定（面试/考试标准）——三句话
- ❌ 不算**输入** `nums`（别人给你的）
- ❌ 不算**输出** `answer`（题目要你返回的）
- ✅ 只算**额外辅助空间**（auxiliary space）

> 依据：LeetCode 238 的 follow-up 问 "Can you solve it in **O(1) extra space**?"
> 这里 "extra space" 明确把输出数组排除在外。

### 2. 如何数空间
- 只用了固定数量的变量（`result`、`i`、`left`、`right`）→ **O(1)**
- 开了 `n` 长的辅助数组（如左积数组、右积数组）→ **O(n)**

---

## 四、复杂度与 LeetCode Constraints 的关系

**Constraints 会暗示你该用什么复杂度：**

| 数据范围 n | 能接受的复杂度 | 典型例子 |
|---|---|---|
| n ≤ 10 | O(n!)、O(2ⁿ) | 回溯、全排列 |
| n ≤ 20 | O(2ⁿ) | 子集枚举 |
| n ≤ 500 | O(n³) | 三层循环 |
| n ≤ 10⁴ | O(n²) | 两层循环、二维 DP |
| n ≤ 10⁵ | O(n log n) 或 O(n) | 排序、一次/多次线性遍历 |
| n ≤ 10⁶ | O(n) | 必须线性 |

> 本题 n ≤ 10⁵ → 只能用 O(n) 或 O(n log n)，O(n²) 会超时。

---

## 五、示例：LeetCode 238 的暴力解

```python
def productExceptSelf(self, nums):
    answer = []
    for i in range(len(nums)):                # 外层 n 次
        result = 1
        for left in range(0, i):              # 内层 ≤ n 次
            result *= nums[left]
        for right in range(i+1, len(nums)):   # 内层 ≤ n 次
            result *= nums[right]
        answer.append(result)
    return answer
```

- **时间**：外层 n × 内层最多 n = **O(n²)**
- **空间**：只多了几个整数变量 = **O(1)**

---

## 六、关键点 / 易错点

1. 时间复杂度问「增长趋势」，不是「秒数」。
2. Big O 只留最高阶项，常数和低阶项全扔掉。
3. 「两层循环」≠ O(n²)，要看内层循环次数是否随 n 增长。
4. 空间复杂度默认不算输入、也不算输出，只算**额外辅助空间**。
5. 拿到题先看 Constraints 的数据范围，反推该用什么复杂度。
