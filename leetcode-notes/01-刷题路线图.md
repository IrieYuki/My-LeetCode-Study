## 三、为什么是这个顺序

- **先数组 / 哈希表再双指针**：哈希表是「用空间换时间」的第一课，双指针是「用顺序换空间」的第一课，两者互补，撑起后面几乎所有题。
- **滑动窗口排在双指针之后**：它就是「双指针 + 一个计数表」，先会走再会跑。
- **栈和队列 → 二分 → 链表 → 树**：栈/队列是后面 BFS/DFS/单调栈的地基；树是链表的二维版，所以链表必须先熟。
- **双指针 → 二分**：都是「利用有序性砍掉一半可能」，思维同源。
- **树 → 回溯 → 动态规划**：树写熟了递归，回溯就是「递归 + 撤销选择」；回溯再往上一层就是 DP。
- **图放在最后**：它是 DFS/BFS + 哈希表的组合应用，前面专题的零件都用得上。
- **难度曲线**：每个专题内部按 Easy → Medium → Hard 排；Hard 只放 5 题（42 / 76 / 84 / 23 / 295），做不出来不算失败，先过。
